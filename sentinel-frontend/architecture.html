System Architecture

A high-performance pipeline bridging edge hardware, biometric AI, and spatial logic.

Tier 01 // Hardware Edge

LoRaWAN NodeMCU

915MHz offline mesh network. Transmits heavily compressed 15-byte GPS packets during total cellular infrastructure failure.

C++ / SPI / LoRa.h
Tier 01 // Public Edge

React Native App

Public-facing mobile application for uploading real-time tips, CCTV frames, and spatial sightings over standard cellular.

TypeScript / React Native
Tier 02 // API Gateway

FastAPI Event Loop

Asynchronous Python backend built on Uvicorn. Handles incoming hardware webhooks, authenticates JWTs, and streams live data to the dashboard via WebSockets.

Python 3.10 / Pydantic / WebSockets
Tier 02 // AI Processor

DeepFace Engine

VGG-Face biometric model. Computes cosine similarity between injected CCTV frames and the P0 target's baseline hash to automatically discard false positives.

TensorFlow / DeepFace / Cosine Distance
Tier 03 // Persistence

PostgreSQL + PostGIS

Stores spatial point geometries. Executes Tobler's hiking function to mathematically project search radiuses.
