Data Intelligence Pipeline

Understanding how raw chaos is transformed into actionable tactical intelligence.

1. Processing Pipeline

Phase 1: Raw Ingestion

Intelligence enters the system via two streams: Public (React Native app sending tips over 5G/4G) and Tactical (NodeMCU hardware sending offline GPS pings via 915MHz LoRa mesh).

DATA: { lat: 19.033, lng: 73.029, img: , timestamp: int }

Phase 2: DeepFace Biometric Triage

Before a tip hits the dashboard, it is intercepted by the ML pipeline. If the tip contains CCTV or smartphone imagery, the VGG-Face model extracts a 2622-dimensional facial vector and computes the cosine distance against the missing subject's baseline vector.

EVAL: Cosine Distance = 0.18 -> MATCH CONFIRMED (P0 Status Assigned)

Phase 3: Spatial Projection (PostGIS)

Once verified, the coordinate is stored in PostgreSQL. The system uses Tobler's Hiking Function to calculate the maximum theoretical walking distance from that point based on elapsed time and terrain elevation logic, generating a search radius polygon.

Phase 4: Tactical Distribution

The verified data is pushed over WebSockets directly to the Command Dashboard. The UI immediately renders a glowing red reticle at the exact coordinate, bypassing standard polling delays.

2. System Terminology (Glossary)

Nomenclature Definition & Context
LKP Last Known Position The verified starting coordinate used by the ML model to begin plotting the search radius.
[CRIT] / P0 Priority Zero (Critical Match) A tip that has been passed through the DeepFace neural network and yielded a high-confidence biometric match. It triggers red alerts on the dashboard.
Tobler's Radius Mathematical Spatial Boundary A non-circular polygon on the map calculated using Tobler's hiking function. It shows exactly how far a human could walk considering the local terrain and time elapsed since LKP.
LoRa MESH Long Range Offline Network A decentralized radio network used by responders when standard cell towers fail. Nodes relay tiny 15-byte GPS packets to each other until they hit the Command Center.
C4I Command, Control, Comm, Computers, Intel The military terminology for the overall architecture of this dashboard. It acts as the brain of the search operation.
PuLP Optimizer Linear Programming Engine An upcoming feature. A backend python algorithm that calculates the most efficient way to assign available volunteers to open search sectors based on real-time distances.
