# SENTINEL - How to Get Current Live Satellite Data for Free

Yes! You can get **current live satellite imagery (updated every 1 to 5 days)** for **100% free** without any paid subscription or API key.

---

## 🚀 1. Primary Option: ESA Sentinel-2 L2A (10m Resolution, 5-Day Revisit)

Sentinel-2 consists of two twin satellites (Sentinel-2A and Sentinel-2B) orbiting Earth. Every point on Earth (including Navi Mumbai) is photographed **every 5 days**.

### 🔗 Direct Live Portal:
* **Copernicus Browser**: [https://browser.dataspace.copernicus.eu/](https://browser.dataspace.copernicus.eu/)

### 🗺️ How to View Today's / Recent Satellite Pass (Step-by-Step):
1. Click [Copernicus Browser](https://browser.dataspace.copernicus.eu/).
2. Type **Navi Mumbai** in the search box.
3. On the left panel under **Data Sources**, check **Sentinel-2** -> Select **L2A**.
4. Set the **Time Range** (e.g., set the end date to today's date).
5. Click **Search**.
6. You will see satellite photos taken **just a few days ago**!
7. **Live Spectral Indices**:
   - **True Color (RGB)**: See real photos of the ground as it looks right now.
   - **NDVI (Vegetation Index)**: Real-time forest density mask.
   - **NDWI (Water Index)**: Real-time water body mask (lakes, creeks, rivers).

## 🚀 2. Secondary Option: NASA / USGS Landsat 8 & 9 (15m/30m Resolution, 8-Day Revisit)

Landsat 9 is NASA's newest operational earth observation satellite (launched recently), capturing images every 8 days.

### 🔗 Direct Live Portal:
* **NASA Worldview**: [https://worldview.earthdata.nasa.gov/](https://worldview.earthdata.nasa.gov/)
* **USGS EarthExplorer**: [https://earthexplorer.usgs.gov/](https://earthexplorer.usgs.gov/)

### 🗺️ How to View in NASA Worldview:
1. Open [NASA Worldview](https://worldview.earthdata.nasa.gov/).
2. Zoom into **India -> Maharashtra -> Navi Mumbai**.
3. Use the timeline slider at the bottom to drag to **yesterday's or today's date**.
4. You will see near-real-time satellite imagery collected by NASA satellites within the last 3 to 24 hours!

---

## 🚀 3. Real-Time Fire / Disaster Data: NASA FIRMS (Updated every 3 hours)

If you need thermal/disaster sighting data for emergency SAR:
* **NASA FIRMS**: [https://firms.modaps.eosdis.nasa.gov/usng/](https://firms.modaps.eosdis.nasa.gov/usng/)
* Detects active thermal anomalies / fires updated **every 3 hours** worldwide for free.
